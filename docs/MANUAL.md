# 手动模拟装柜 · 交互草案（V1）

主界面就是现在的 3D 视图，切到「手动模拟」标签后启用；容器参数与自动计算共用同一份。

## 1. 进入手动模式

- 顶部两个标签：`自动计算` / `手动模拟`。切到手动时，若已有自动方案，弹一句
  「以本次自动方案为起点？[以它开始] [空柜开始]」，默认「以它开始」（见第 6 节）。
- 3D 视图保留现有的旋转、缩放、平移；柜体线框、门高标注不变。

## 2. 添加纸箱

- 工具栏「＋ 添加纸箱」：下拉选箱型（复用纸箱清单里的 SKU，也可临时新建），
  点一次就在**柜门外侧**生成一只，落在地面格栅上，位置错开摆放避免重叠。
- 新箱生成时即被选中，周围有一圈高亮描边。

## 3. 拖动与吸附

- 用左键按住箱体拖动：拖动中箱体半透明跟随，下方投一条垂直参考线到地面。
- 松手时按三步定位置：
  1. **沉降**：落到正下方最高的水平支撑面（即该箱底面矩形被真实顶面完全覆盖的最高高度）。
  2. **贴齐**：在 50mm 容差内，向最近的柜壁（内壁 4 面）或相邻箱面（前后左右）贴齐；
     吸附成功后该方向短暂高亮 200ms，并在状态栏写「已贴齐：后壁 / 左侧 32mm」。
  3. **判定**：越界（超出内腔）或与已有箱体重叠 → **拒绝落位**，箱子变红 300ms 后
     弹回原位，状态栏写原因（越界 42mm / 与第 3 层第 7 箱重叠）。
- 吸附只处理水平方向贴齐与竖直沉降，不做「自动堆叠成排」这种智能排布——那是自动模式的事。

## 4. 选中与旋转

- 单击选中（描边 + 底部显示该箱坐标与姿态）；空白处单击取消选中。
- 键盘 `Q / E` 或工具栏三个按钮：绕竖直轴 / 绕长度轴 / 绕宽度轴各转 90°。
- 旋转后立即跑一次摆放判定：不合法就退回旋转前的姿态并提示，合法则重新沉降贴齐。

## 5. 复制与计数

- `Ctrl+C` 记录当前选中箱的箱型与姿态，`Ctrl+V` 在同一位置上方（或最近空位）
  生成一只同款，并被选中；连续 `Ctrl+V` 会依次往上叠，直到放不下为止。
- 底部状态条：每种箱型 `已放 / 需求`，例如 `吧椅 12/130`、`斜顶箱 #2 4/190`；
  未填需求的箱型只显示已放数。

## 6. 与自动计算的关系

- 自动方案的 `pack.placements` 可以直接灌进手动模型（字段一致：skuId / x,y,z / l,w,h / pose），
  所以「以自动方案为起点再手动微调」是**增量功能，不是重做**。
- 进入手动模式时可选择「清空重来」，也可以「保留并继续」。

## 7. 体检

- 手动方案跑同一套校验：越界、两两重叠、悬空/压斜面三项；底部「本单体检」实时更新。
- **悬空不阻断**：按 Chief 定，允许摆，但该箱立刻标黄并计入体检。
  理由是手动模式就是用来试「这样摆行不行」的，硬拦会让操作频繁失败。

## 8. 移动端（390 宽）

- 拖拽在手机上不可靠：V1 用「点选中 → 方向键/按钮微调 10mm、50mm 两档」替代拖拽，
  旋转、复制、删除都做成底部工具栏按钮；桌面端才启用拖拽。

## 9. 补充规则（Chief 定，V1 必须实现）

1. **撤销与删除**：`Ctrl+Z` 至少 20 步（记录每次放置/旋转/复制/删除前后状态），`Delete` 删掉选中箱。
   手动模式没有撤销，摆错一次只能拖回去，太折腾。
2. **拖拽落点用射线**：跟随位置由射线命中「柜底面或已有箱顶」决定，不允许悬在任意高度。
   否则用户以为自己放高了，松手才发现被沉降了。
3. **复制规则写死**：`Ctrl+V` 优先原位向上叠（上方支撑完整才允许）；不行就沿贴齐方向找最近空位；
   都失败就拒绝并提示「上方与四周都没有空位」，不出现“凭空生成一只”。
4. **快捷键作用域**：`Ctrl+C/V/Z` 与 `Delete` 只在 3D 区域有焦点时生效并 `preventDefault()`；
   焦点在输入框或页面文字上时不拦截，否则会吃掉用户正常的复制。
5. **旋转后的顺序固定**：旋转 → **重新沉降** → 摆放判定 → 不合法才退回原姿态。
   旋转后高度经常变化，不重沉降会把箱子留在空中。

## 验收（与 Chief 定的六条一致）

1. 拖放后位置与吸附结果误差 ≤ 50mm
2. 非法落位被拒绝并回弹
3. 三轴旋转后姿态与 `solid.js` 采样一致
4. 复制后底部计数 = 实际摆放数
5. 手动方案能跑同一套体检，报越界 / 重叠 / 悬空
6. 390 宽度下可点选、可旋转（拖拽用点选加按钮替代）

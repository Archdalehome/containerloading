# 集装箱装柜计算器（Container Loading）

输入纸箱尺寸、形状和数量，选集装箱规格，算出能装多少、怎么排，并生成可旋转的 3D 装柜图。
纯静态页面（HTML + CSS + 原生 JS，无构建步骤、无 CDN），部署在 Cloudflare Pages。

## 单位与约束

- 内部计算一律 **毫米（mm）**，重量 **千克（kg）**；显示时换算成米 / 立方米。
- **箱体高度不得超过门高**：40HQ 内高 2698 但门高只有 2585，超过门高的箱子进不去。
  超过内高报内高错误，超过门高但低于内高报门高错误。
- 单箱底面最短边超过内宽、或最长边超过内长时直接判为装不进去。

## 排布口径（第一版）

L 形箱与斜顶箱的**净体积**按真实几何计算，但**排布**一律按**外接长方体**占位（保守估算），
3D 图中按真实几何渲染。形状咬合、翻转嵌套排布属于第二版，第一版不做，界面上已明确写出这一点。

## M2 算法（待实现，先记下口径）

按体积从大到小，逐层装：每层取当前最大未装完 SKU，用它的外接底面在 L×W 内货架式排布
（沿宽排一行、整行推进，允许水平 90° 旋转），层厚 = 箱高；累加层高，超过内高或超过最大载重就停。

基准例：400×300×300 装 40HQ（12032×2352×2698）
- 沿长：12032 ÷ 400 = 30 个（余 32mm）
- 沿宽：2352 ÷ 300 = 7 个（余 252mm）
- 沿高：2698 ÷ 300 = 8 层（余 298mm）
- 合计 30 × 7 × 8 = **1680 箱**，即每层 210 箱、8 层。
- 体积：1680 × 0.036 = 60.48 m³，集装箱内容积 12032×2352×2698 ≈ 76.36 m³，装载率约 79.2%。
- 载重：每箱 > 15.77kg 就会先撞 26500kg 上限（1680 × 15.77 ≈ 26500）。
